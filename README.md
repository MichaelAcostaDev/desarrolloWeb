# Desarrollo Web

> **My first website — 2023** 

This project represents an important milestone in my journey as a developer: **my first website and my first practical interaction with programming, created in 2023.**

The original project was built as an experiment to learn how websites work, how different pages connect, and how to structure a web project. The version currently available in this repository was later adapted to **PHP**, while preserving the original concept and purpose of the project.

It is not intended to represent my current level of development. Instead, it serves as a record of where my journey in web development began.

## 🧩 A Piece of My Development Journey

This project is particularly meaningful because it documents the beginning of my path into software development.

In **2023**, I created this website while I was beginning to understand web development and programming. At that stage, the objective was not to build a production-level application, but to experiment, learn, make mistakes, and understand how the different pieces of a website worked together.

Looking back at this project is a way of seeing the progression from my first experiments with programming to the more complex applications I build today.

**Every developer has a first project. This is mine.**
